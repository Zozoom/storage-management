# Security Policy

## Reporting a vulnerability

Please do not report security problems in a public issue. Report them privately on GitHub: open the **Security** tab of this
repository and choose **Report a vulnerability** (https://github.com/Zozoom/storage-management/security/advisories/new).

Please describe the problem, the affected version and the steps to reproduce it. We will confirm that we received the report and
keep you informed while we work on a fix.

## Supported versions

Security fixes are made on the default branch and go into the next release.
